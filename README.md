# hxwl-10 考古探方记录

遗址探方、地层关系与出土物坐标档案 —— 地层与出土物联审闭环。

## 技术栈

React + Vite + TypeScript + CSS，localStorage 落盘，JSON 导入导出。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5110

## 联审闭环规则

| 规则 | 内容 |
| --- | --- |
| R1 | 出土物坐标必须落在探方边界内 |
| R2 | 地层连续登记：后一层顶深必须等于前一层底深（第一层接续地表起算深度） |
| R3 | 出土物只能归入已登记地层 |
| R4 | 出土深度必须落在所属地层顶底深之间 |
| R5 | 探方确认后地层冻结，禁止直接登记/改动 |
| R6 | 冻结后纠错只能新建带原因的修订，旧版全程保留在修订链中 |

所有写入（登记探方/地层、出土物入档、确认冻结、提交修订、导入档案）都先经
`src/rules.ts` 规则引擎校验：通过才落盘，被拦截时在冲突清单中列出
**探方、地层、坐标、字段、原值、提交值与触发规则**。

## 功能

- 探方登记（编号唯一、边界合法），登记中/已确认两种状态
- 地层柱可视化：按土色着色、按厚度比例绘制，顶深自动接续上一层底深
- 出土物入档：地层下拉只列已登记地层，坐标与深度越界即拦截
- 联审确认：确认前整链复核，确认后冻结
- 修订工作流：冻结后纠错生成带原因修订，修订不得破坏链连续、不得使已入档出土物越界；旧版留档可查
- 全量复核：一键审计当前档案的探方、地层、出土物与修订链一致性
- 落盘与迁移：每次成功写入即持久化；刷新后档案一致；导出/导入 JSON，导入先审后入，冲突即拒
